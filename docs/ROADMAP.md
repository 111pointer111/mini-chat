# Mini-Chat 功能规划文档

## 项目愿景

打造一个功能丰富的智能聊天平台，支持多种登录方式、AI 对话、图片消息和定时任务。

---

## 一、登录认证系统

### 1.1 手机号登录 ⭐ 优先级：高

- [ ] 短信验证码发送（阿里云/腾讯云短信服务）
- [ ] 手机号注册
- [ ] 手机号登录
- [ ] 手机号绑定（已有账号绑定手机）

### 1.2 QQ 登录 ⭐ 优先级：中

- [ ] QQ 互联 OAuth 2.0 接入
- [ ] QQ 账号关联/绑定
- [ ] 获取 QQ 头像和昵称

### 1.3 微信登录 ⭐ 优先级：低（需企业资质）

- [ ] 微信开放平台 OAuth 接入
- [ ] 微信账号关联/绑定

### 1.4 找回密码

- [ ] 通过手机号找回（发送验证码）
- [ ] 通过 QQ 邮箱找回（发送验证链接）
- [ ] 重置密码流程

---

## 二、图片消息功能 ⭐ 优先级：高

### 2.1 图片上传

- [ ] 聊天界面添加图片发送按钮
- [ ] 支持选择图片/拍照上传
- [ ] 图片预览功能

### 2.2 云存储

- [ ] 接入云存储（Cloudflare R2 / 阿里云 OSS）
- [ ] 图片自动压缩（使用 sharp 库）
- [ ] 生成缩略图存储
- [ ] 原图按需加载

### 2.3 消息展示

- [ ] 聊天气泡支持图片类型
- [ ] 点击图片查看大图
- [ ] 图片加载状态显示

---

## 三、定时任务功能 ⭐ 优先级：中

### 3.1 预设定时任务（第一阶段）

- [ ] 后端维护预设任务列表
- [ ] 用户可启用/禁用任务
- [ ] 用户可设置执行时间
- [ ] 任务触发时调用 AI 生成回复

**预设任务示例**：
- 每日问候
- 周报提醒
- 学习打卡提醒
- 天气播报

### 3.2 自定义定时任务（第二阶段）

- [ ] 用户自定义任务名称
- [ ] 用户自定义触发时间
- [ ] 用户自定义 AI 提示词
- [ ] 任务管理界面

---

## 四、AI 机器人系统 ⭐ 优先级：高（创意功能）

### 4.1 多机器人支持

- [ ] 支持创建多个 AI 聊天窗口
- [ ] 每个窗口可选择不同的机器人角色
- [ ] 机器人角色独立对话历史

### 4.2 预设机器人角色

| 角色 | 描述 | 系统提示词特点 |
|------|------|---------------|
| 通用助手 | 默认 AI 助手 | 通用问答 |
| 机器人女友 | 温柔体贴的虚拟伴侣 | 情感陪伴、日常聊天 |
| 淘宝客服 | 模拟电商客服 | 商品咨询、售后服务 |
| 英语老师 | 英语学习助手 | 纠错、翻译、口语练习 |
| 代码助手 | 编程辅助 | 代码解释、Bug 修复 |
| 心理咨询师 | 情感倾诉 | 倾听、开导、建议 |
| 健身教练 | 运动指导 | 训练计划、饮食建议 |
| 面试官 | 模拟面试 | 提问、反馈、建议 |

### 4.3 角色定制

- [ ] 系统提示词配置
- [ ] RAG 知识库接入（可选）
- [ ] 角色头像和名称自定义
- [ ] 对话风格参数调整（温度、长度等）

### 4.4 用户自定义角色（高级）

- [ ] 用户创建自定义机器人
- [ ] 自定义系统提示词
- [ ] 上传知识库文档
- [ ] 分享机器人给其他用户

## 开发阶段规划

### 第一阶段：核心功能完善

1. 手机号登录 + 找回密码
2. 图片消息 + 云存储
3. AI 多机器人系统

### 第二阶段：社交功能

1. QQ 登录
2. 群聊功能
3. 消息搜索与收藏

### 第三阶段：高级功能

1. 预设定时任务
2. 语音消息
3. AI 图片生成

### 第四阶段：扩展功能

1. 自定义定时任务
2. 用户自定义机器人
3. 微信登录（需企业资质）

## 技术栈补充

| 功能 | 技术方案 |
|------|----------|
| 短信服务 | 阿里云短信 / 腾讯云短信 |
| 云存储 | Cloudflare R2 / 阿里云 OSS |
| 图片处理 | sharp |
| 定时任务 | node-cron / agenda |
| OAuth | passport / 手动实现 |
| 语音识别 | OpenAI Whisper |
| 图片生成 | DALL-E / Stable Diffusion |
